# USB Device Monitor

A simple Python-based USB device monitoring tool for Linux using pyudev.

## Features
- Detect USB device connection
- Detect USB device removal
- Real-time monitoring
- Lightweight and easy to use

## Requirements

pip install pyudev

## Usage

python3 usb_monitor.py                                                                                                                                                                                                                                                                                                                                                                                                        ## Technologies Used

- Python 3
- pyudev
